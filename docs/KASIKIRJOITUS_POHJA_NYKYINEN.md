# Laturaivo - Kasikirjoituspohja (nykyinen runko)

## 1) Perustiedot
- Versio: v1
- Paivamaara: 2026-02-26
- Formaatti: pelinsisainen valikerronta (video + still-kuvat + tekstikortit)
- Kesto tavoite: 30-90 s per valikohtaus

## 2) Logline
Keski-ikainen espoolainen mies purkaa padottua raivoaan ladulla ja kohtaa taso tasolta kovenevan vastuksen, kunnes lopussa raivo murtuu hetkeksi hiljaisuudeksi.

## 3) Tyyli ja aani
- Savy: tumma huumori + draama + absurdius
- Kieli: suomi, lyhyet iskevat lauseet
- Rytmi: napakka, 3-8 rivi teksteja per valikohtaus

## 4) Hahmokaari (paahahmo)
- Alku: padottu mieli, hallittu ulkokuori
- Keskiosa: raivo muuttuu voimaksi
- Huippu: raivo antaa vallan, melu kovenee
- Loppu: hiljainen jalkikaiku, hetkellinen itsen voittaminen
